## 链接规则

所有订阅链接使用前缀 `https://raw.githubusercontent.com/zgh990701/LOL-CS-Match-Calendar/main/`，后面拼接对应的文件路径。

| 订阅范围 | 文件路径 |
| --- | --- |
| CS2 总日历 | `cs2.ics` |
| LoL 总日历 | `lol.ics` |
| 某一届 CS2 赛事 | `events/cs2/<赛事届次ID>.ics` |
| 某一届 LoL 赛事 | `events/lol/<赛事届次ID>.ics` |

赛事届次 ID 由 PandaScore 提供。请从目录复制实际链接。同一届赛事的不同赛段共用一个链接，改期或公布比分会更新原有事件。

CS2 覆盖 ESL／IEM、PGL 和 BLAST。LoL 覆盖 LPL、LCK、LEC、LCS、First Stand、MSI 和全球总决赛。目录显示过去 30 天及未来 365 天内已公布开赛时间的赛事。
